# 🧪 PyTest API Testing Framework

A modular PyTest-based API testing framework for testing RESTful CRUD APIs. Perfect for learning or fast regression testing plug-ins.

## 🚀 Features
- Token-based authentication
- Reusable fixtures in `conftest.py`
- GET, POST, PUT, DELETE support
- JSON-based validations
- Lightweight and fast

## 🗂 Folder Structure
```txt
.
├─ tests/
│  └─ test_users.py
├─ utils/
│  └─ logger.py
├─ conftest.py
├─ requirements.txt
├─ pytest.ini
├─ README.md



🎯 How to run
pip install -r requirements.txt
pytest
